Vice City Cover Studio — turn your photo and a caption into GTA 6-style poster cover art: multi-panel layout, Vice City sunset and neon colour grade, bold caption lettering, crop and position each photo, export as PNG in 1080×1080, 1080×1350 or 1920×1080. Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Serve the app locally with `node serve.ts`, then open http://localhost:8080.
